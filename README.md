# XAU Replay

![XAU Replay](public/brand/logo.png)

แอปฝึก Backtest และ Replay ทอง XAUUSD ใช้ได้โดยไม่ต้องสมัครสมาชิก เปิดกราฟย้อนหลัง วางออเดอร์จำลอง แล้วเก็บ P&L, R และบันทึกการเทรดของแต่ละรอบ

**เปิดแอป:** [basssg.github.io/XAUUSDreplay](https://basssg.github.io/XAUUSDreplay/)

## เริ่มใช้งาน

1. เปิดแอปแล้วเลือกชุดข้อมูล วันที่เริ่ม และเงินตั้งต้นของรอบฝึก
2. ตั้ง Stop Loss / Take Profit เลือกความเสี่ยงเป็นเปอร์เซ็นต์หรือกำหนด lot แล้วกด Buy / Sell
3. เดินหน้าหนึ่งแท่งเพื่อจับคู่ออเดอร์ หรือกด Play และปรับความเร็ว กด Pause เมื่อจะตัดสินใจ
4. ดู Positions และ Journal เพื่อปิดบางส่วน ย้าย SL ไป Breakeven ใส่โน้ต และตรวจ P&L / R
5. ย้อนกลับเพื่อทบทวน เมื่ออยากลองตัดสินใจใหม่ให้สร้างรอบแยกจากจุดนั้น รอบเดิมยังเก็บไว้

บนคอมพิวเตอร์ใช้ Space เพื่อ Play / Pause และลูกศรเพื่อเดินหน้าหรือย้อนแท่งได้ กราฟและอินดิเคเตอร์ใช้เฉพาะข้อมูลถึงจุด Replay ที่กำลังดู

## ติดตั้งเหมือนแอป

- **Windows / macOS:** เปิดด้วย Chrome หรือ Edge แล้วใช้เมนูติดตั้งแอปของเบราว์เซอร์ หรือปุ่มติดตั้งใน XAU Replay เมื่อเบราว์เซอร์รองรับ
- **iPhone / iPad:** เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดเป็นเว็บแอป → เพิ่ม ชื่อเมนูอาจต่างกันตามเวอร์ชัน iOS / iPadOS
- **Android / tablet:** เปิดด้วย Chrome แล้วเลือกติดตั้งแอปหรือเพิ่มไปยังหน้าจอหลัก

การติดตั้งใช้เว็บแอปเดียวกัน ไม่ต้องดาวน์โหลดไฟล์ APK หรือโปรแกรมติดตั้ง เปิดออนไลน์ครั้งแรกเพื่อโหลดแอปและข้อมูลราคา หลังจากนั้นส่วนแอปและช่วงข้อมูลที่เคยโหลดสามารถใช้จากแคชได้ ข้อมูลช่วงใหม่และการดึง API ล่าสุดต้องใช้อินเทอร์เน็ต

คำแนะนำจากผู้ผลิต: [ติดตั้งบน iPhone / iPad](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios), [ติดตั้งเว็บแอปใน Chrome](https://support.google.com/chrome/answer/9658361)

## เก็บรอบและย้ายอุปกรณ์

รอบฝึก ออเดอร์ โน้ต และไฟล์ราคาที่นำเข้าเก็บใน IndexedDB ของเบราว์เซอร์บนเครื่องนั้น แต่ละอุปกรณ์มีสมุดบันทึกของตัวเอง ไม่มีบัญชีผู้ใช้และไม่มีการซิงก์ข้ามอุปกรณ์อัตโนมัติ

ใช้ **สำรองข้อมูล** เพื่อดาวน์โหลดไฟล์ JSON แล้ว **นำเข้าข้อมูลสำรอง** บนเครื่องใหม่ได้ ข้อมูลรอบฝึกเดิมจะยังอยู่ หากนำเข้ารอบชื่อเดียวกันแต่ข้อมูลต่างกัน แอปสร้างรอบสำเนาแยกให้ การล้างข้อมูลเว็บไซต์หรือถอนข้อมูลเบราว์เซอร์อาจลบรอบที่เก็บในเครื่อง จึงควรเก็บไฟล์สำรองไว้อีกที่ก่อนย้ายเครื่องหรือล้างข้อมูล

CSV ของ Journal ใช้ดูผลการเทรด ส่วน JSON สำรองใช้คืนรอบฝึกพร้อมข้อมูลที่จำเป็น การเปิดเว็บและแอปที่ติดตั้งอาจใช้พื้นที่จัดเก็บต่างกันตามเบราว์เซอร์และระบบปฏิบัติการ

ไฟล์ราคาถูกแบ่งและบีบอัดเป็น gzip เพื่อโหลดเป็นช่วง พร้อม SHA-256 ของแต่ละไฟล์ ไม่ต้องดึง API เพื่อเริ่มฝึกจากชุดข้อมูลนี้ ข้อมูล 1m ไม่ได้ครอบคลุมปี 2021 เพราะไฟล์ต้นทางเริ่มเดือนมิถุนายน 2026

เวลา CSV ตรงกับ `raw_time` ตามนาฬิกาโบรกเกอร์ แปลงเป็น UTC ด้วย offset ฤดูหนาว 2 ชั่วโมง / ฤดูร้อน 3 ชั่วโมงตาม US DST และเก็บขอบเขตแท่งของโบรกเกอร์ ตรวจเทียบเวลากับ API 18,000 แท่งแล้วไม่พบความต่าง รายละเอียด: [รายงานตรวจข้อมูล](docs/history-quality.json)

แหล่งข้อมูล: [ไฟล์ประวัติ](https://theft-volatile-relock.ngrok-free.dev/download/data/), [คำอธิบายต้นทาง](https://theft-volatile-relock.ngrok-free.dev/download/data/README.txt), [API ล่าสุด](https://theft-volatile-relock.ngrok-free.dev/api/bars/all) ที่มีข้อมูลล่าสุดประมาณ 3,000 แท่งต่อ timeframe ปุ่มดึงล่าสุดนำเข้าสแนปช็อตสำหรับฝึก ไม่ใช่การส่งคำสั่งซื้อขายจริง

## Pine Script และอินดิเคเตอร์หลายตัว

เปิด **Indicators** แล้วกด **เพิ่ม All Indy + EBW-Fibo ฉบับเต็ม พร้อมเชื่อม Zone Bridge** เพื่อใช้สอง source ที่เจ้าของโครงการส่งมา หรือวาง Pine ใน Editor / เลือกไฟล์ .pine หรือ .txt แล้วกด Add & Run เพิ่มหลายตัวพร้อมกันได้ ไม่มีเพดานจำนวนตัวใน UI; ความเร็วและหน่วยความจำขึ้นกับสคริปต์และเครื่อง

- All Indy V10.4.4: source เต็ม 212,346 ตัวอักษร รวม Stochastic, RSI, โซน, planner และ Zone Bridge
- EBW-Fibo 1.9: source เต็ม 103,937 ตัวอักษร รวม Hero TF, Fibonacci, strength map และ Zone Bridge inputs
- สองไฟล์ต้นฉบับเก็บใน public/indicators/*-full.pine โดยไม่ตัดท้าย ตรวจ SHA-256 ก่อนนำเข้าตัวที่ติดมากับแอป
- Zone Bridge เชื่อม 17 ช่องจาก All Indy ไป EBW-Fibo อัตโนมัติ ตามเวลาของแท่ง ทั้งสองตัวต้องเปิดอยู่ ตัวส่งออกยังยึดเงื่อนไขความพร้อมของโซนตามสคริปต์
- กด **แก้ไข** ในรายการ เพื่อค้นหา/ปรับ inputs ตามกลุ่ม และเปิด Dashboard หากต้องการ: source All Indy ตั้ง Show dashboards เป็นปิดไว้ตั้งแต่ต้น
- บันทึก source, inputs และสถานะเปิด/ปิดไว้ในรอบฝึกและ JSON สำรอง
- สคริปต์รุ่นเดิมที่ถูกตัดในเว็บจะอัปเดตเป็นฉบับเต็มเมื่อเปิดรอบ หาก hash ตรงฉบับเดิมที่แอปเคยแจก โค้ดที่ผู้ใช้แก้เองจะไม่ถูกแทนที่

ใช้ [PineTS 0.11.0](https://github.com/LuxAlgo/PineTS) ใน Web Worker รองรับชุดอินดิเคเตอร์นี้, plot/hline, inputs, request.security/security_lower_tf, line/box/label/linefill/table และ force_overlay แยก oscillator ตามตัวอินดิเคเตอร์ การร้องขอ timeframe ใช้ข้อมูลย้อนหลังที่มี ณ จุด Replay และประกอบแท่งใหญ่ที่ยังไม่ปิดจากข้อมูลที่เปิดแล้ว

Runtime ยังเป็น **beta** และยังไม่ได้เทียบทุกค่า/ทุก input กับ TradingView โดยตรง ยังไม่รองรับ library import ภายนอก, อินดิเคเตอร์ล็อก source, การเชื่อม strategy() เข้ากับสมุดออเดอร์, plot offset และภาพทุกประเภทของ Pine เช่น custom candle/bar/background หรือวัตถุใน oscillator บางชนิด สคริปต์ที่ compile ไม่ผ่านและฟีเจอร์บางประเภทที่ยังไม่รองรับจะแจ้งสถานะในแอป

ข้อความ ป้ายบนอินดิเคเตอร์ และ Dashboard ซ่อนเป็นค่าเริ่มต้น เปิดกลับได้ที่ปุ่ม **ข้อความอินดี้** / **Dashboard** บนกราฟ การเปิดปิดนี้ไม่เริ่มคำนวณ Pine ใหม่ และจำการตั้งค่าไว้ในเครื่อง เส้น โซน สี ลูกศร และ SL/TP ยังแสดงตามปกติ

การโหลดสองสคริปต์ใหญ่ครั้งแรกอาจใช้เวลา 1–2 นาทีบนเครื่องทดสอบ หลังจากนั้นเดินหน้าใช้สถานะเดิม และย้อนจุดที่เพิ่งดูใช้ผลที่แคชไว้ หากย้อนออกจากแคชหรือเปลี่ยน inputs/timeframe จะคำนวณใหม่ ตอน Play หรือกดทีละแท่ง ระบบเตรียมผลของจุดถัดไปแยกจากหน้าจอ แล้วแสดงราคา ออเดอร์ เวลา และอินดิเคเตอร์พร้อมกัน ภาพปัจจุบันจึงไม่หายระหว่างคำนวณ และไม่มีผลจากจุดข้างหน้าแสดงก่อนเวลา Pause ยกเลิกการเดินหน้าที่รออยู่ ความเร็วจริงสูงสุดขึ้นกับความซับซ้อนของอินดิเคเตอร์และอุปกรณ์

## เครื่องมือกราฟและ SL / TP

แถบเครื่องมือมี Cursor, เส้นแนวนอน/แนวตั้ง, Trend, Ray, Zone, Fibonacci, Measure, Range, Text, Magnet, ซ่อนรูปวาด, Undo/Redo และรายการวัตถุ พร้อม Fit, Reset, ขยายกราฟและส่งออก PNG

ลากตัวจับ SL / TP บนกราฟได้ทั้ง draft และ Position ที่เปิดอยู่ เลือกออเดอร์จากรายการเหนือกราฟ สำหรับ Pending ลาก Entry ได้ด้วย Draft ปรับช่องราคาและ RR ทันที ส่วนคำสั่งแก้ Position/Pending มีผลแท่งถัดไปตามกติกาจำลอง ลาก SL แล้ว TP ในแท่งเดียวกันจะเก็บทั้งสองค่า 1R ยังคงอิง SL แรกของ Position

ตัวจับใช้ Pointer Events สำหรับเมาส์และการแตะ สามารถเลือกตัวจับแล้วใช้ลูกศรขึ้น/ลงเพื่อปรับทีละ tick หรือ Shift เพื่อปรับครั้งละ 1 USD

## กติกาจำลอง

- ออเดอร์เข้าและการปิดด้วยมือจับคู่ที่ราคาเปิดแท่งถัดไปหลังส่งคำสั่ง
- ถ้า SL และ TP ถูกแตะในแท่งเดียวกัน เลือก SL ก่อนและทำเครื่องหมายใน Journal หากเปิดข้ามระดับ ใช้ราคาเปิดจริงตามแบบจำลอง
- Limit ที่เข้าระหว่างแท่งจะไม่รับ TP จาก high/low ที่อาจเกิดก่อน Entry เว้นแต่ราคาปิดพิสูจน์ว่าแตะ TP หลังเข้า; Pending ที่ gap ข้าม SL/TP ถูกปฏิเสธก่อนสร้าง Position
- 1R ยึดความเสี่ยงจากราคาเข้าและ SL แรก แม้ปิดบางส่วนหรือย้าย SL แล้ว ต้นทุนการเทรดไม่รวมในตัวหาร R
- ปรับ spread, slippage, commission และ contract size ได้เมื่อสร้างรอบ กติกาและชุดข้อมูลถูกตรึงไว้ในรอบนั้น
- ค่าเริ่มต้น contract size 100 และ spread 0.16 USD เป็นสมมติฐานของแอป OHLC ต้นทางยังไม่ยืนยันว่าเป็น bid หรือ midpoint จึงจำลองเป็น midpoint พร้อม spread ที่กำหนด
- เป็นการจำลองจาก OHLC ไม่มี swap, margin call หรือ order book; Drawdown วัดที่จุดปิดแท่ง

## พัฒนาและเผยแพร่

ต้องใช้ Node.js 22.13 ขึ้นไป แนะนำ Node.js 24

```bash
npm ci
npm run dev
```

เปิด [http://127.0.0.1:5199/XAUUSDreplay/](http://127.0.0.1:5199/XAUUSDreplay/)

```bash
npm test
npm run build
npm run preview
```

ตรวจ TypeScript ก่อน build จากนั้นสร้าง service worker และไฟล์ใน `dist` การ push ไป `main` จะให้ [GitHub Actions](.github/workflows/deploy.yml) ตรวจและเผยแพร่ GitHub Pages ผู้ดูแลต้องตั้ง Pages เป็น **GitHub Actions** ใน Settings → Pages

ถ้าต้องจัดเตรียมข้อมูลใหม่ ใช้ CSV ต้นฉบับที่มีชื่อทั้งหกไฟล์ตามแหล่งข้อมูล:

```bash
npm run data:prepare -- "/path/to/history"
```

เมื่อเพิ่มข้อมูลใหม่ สคริปต์จะเก็บชุดข้อมูลและ catalog เดิมไว้ด้วยเพื่อให้รอบฝึกและไฟล์สำรองเดิมเปิดได้ ห้ามลบชุดราคาที่รอบเก่ายังอ้างอิงอยู่

การทดสอบอัตโนมัติตรวจ replay engine, การเก็บข้อมูล / backup และ service worker การติดตั้งและการแตะใช้งานบนเครื่องจริงควรตรวจบนอุปกรณ์ปลายทางด้วย
